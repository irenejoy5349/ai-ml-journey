# Student Performance Analysis

## Project Overview

This project analyzes student performance data using Python,
NumPy, Pandas, Matplotlib and Seaborn.

The goal is to understand student performance patterns
through data analysis and visualization.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed

- Loaded student dataset using Pandas
- Checked dataset information
- Checked missing values
- Checked duplicate records
- Created Average Score feature
- Analyzed relationships between features
- Created visualizations

## Visualizations

- Study Hours vs Average Score Scatter Plot
- Average Score Distribution Histogram
- Feature Correlation Heatmap

## Key Insights

- Students with higher study hours tend to have better scores.
- Score distribution helps understand overall performance.
- Correlation analysis helps identify relationships between features.
